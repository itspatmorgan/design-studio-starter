# Studio UI copy

Apply these rules when adding or changing Studio interface text, including platform and module actions.

- Never append ellipses (`…` or `...`) to button or menu action labels. Use **Duplicate**, not **Duplicate…**, even when the action opens a dialog or requires another step.
- Use plain pending button labels, such as **Saving** or **Creating**, without ellipses.
- Ellipses in action labels are allowed only for actual text truncation when the available space cannot show the full label. Prefer CSS truncation and keep the full accessible label.
