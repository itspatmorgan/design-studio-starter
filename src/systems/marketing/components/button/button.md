## When to use

Use Primary for the main action, Secondary for an alternative, and link variants for lightweight navigation. Supply `href` for navigation; use `onPress` for an action.

Marketing includes two sizes (`sm`, `lg`) and four colors (`primary`, `secondary`, `link-color`, `link-gray`). Loading and disabled states retain React Aria behavior.

This is an adapted MIT component from [Untitled UI](https://github.com/untitleduico/react). See [source and adaptations](/systems/marketing/context/library) before extending the inventory.
