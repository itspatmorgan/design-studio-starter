## When to use

Use a tooltip for a short explanation of a control. Keep essential information visible on the page. Wrap its focusable control with `TooltipTrigger`.

This adapted Untitled UI component uses React Aria's portal-container option and Studio's shared container context. Its popup stays in the owning system; it must not attach to the global document body. Motion variants are omitted from this starter inventory.
