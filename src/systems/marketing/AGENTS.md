# Marketing system instructions

This system supports public-facing Design Studio marketing prototypes. Read [Design Studio brand](context/brand.md) for visual direction and [Marketing library](context/library.md) for the imported subset and adaptation choices. Follow the repository's platform working context.

Use Marketing components and `@untitledui/icons`. Compose page sections inside the prototype. Do not import Platform or Product components, or expand the token inventory to the upstream catalog. Keep React Aria popups in the shared themed portal container.

Follow [Marketing design](context/design.md) when composing or revising marketing pages and project artifacts.
