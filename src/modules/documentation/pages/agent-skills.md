A skill gives your agent instructions for a particular task. Studio includes skills for building prototypes, writing documents, creating diagrams, and other capabilities.

Describe the result you want. You do not need to know a skill's name. The agent selects relevant instructions and uses your product context to shape the work.

## Understand what guided the result

If a result surprises you, ask:

> Which guidance did you use, and how did it shape this design?

This can help you decide whether to clarify your request, revise shared knowledge, or ask the agent to correct the implementation.

Read Studio's skills in **Documentation → Context & Skills**. Product-specific skills live in **Systems**. [Product knowledge](/documentation/guide/agent-context) explains how context and skills support your work.

## Add a recurring task

Ask your agent to create a skill when a useful workflow should recur across your product's prototypes. For example, it could review interface copy against your team's standards.

Ask it to make the skill available in your coding tool as part of that work. If the skill does not appear, try a new chat or ask the agent to check its registration. You do not need a new skill for every request.
