# Views

The required Views module opens `.tsx` and `.jsx` files inside prototypes as React pages. Each view exports a React component as its default export. Underscore helpers are excluded from navigation.

The loader inventories views from prototype roots and registered module sections. Preview, source editing, fidelity, and embedding follow the shared [file-type contract](../../platform/core/fileTypes.md). Prototype creation and system assignment follow [Prototypes](../prototypes/README.md).
