# Design Studio

An open-source prototype sandbox for designers and builders working with coding agents.

## Install

Choose **Use this template** at https://github.com/itspatmorgan/design-studio-starter to create your own repository. Clone that copy, never the starter repository directly.

Install mise: https://mise.jdx.dev/installing-mise.html

Replace YOUR-ACCOUNT and YOUR-STUDIO with your GitHub account and new repository name.

```sh
git clone https://github.com/YOUR-ACCOUNT/YOUR-STUDIO.git
cd YOUR-STUDIO
mise install
mise exec -- pnpm install
mise exec -- pnpm dev
```

Open the local URL printed by Vite.

## Use

Read README.md and AGENTS.md before changing files. Follow the setup guide to configure studio identity and the contributor. Resolve the assigned system before editing a prototype.

A prototype keeps views, diagrams, canvases, and documents together. Its assigned system supplies the theme, components, context, rules, and skills.

This marketing project uses the Marketing system: Plus Jakarta Sans, warm neutrals, and adapted Untitled UI components. Captured product examples use a separate Product system. Studio supplies the shared artifact tools.
